Hi, I'm Research Assistant from Newcastle University in the UK, I would like to introduce how we integrate Machine Learning workflow into LibreLane, an open-source EDA framework.

Open-Source EDA Tools

Commercial EDA Tools

Instead of using Cadence and Synopsys, we use Librelane, an open-source framework for EDA Design. Open-source means we can write a plugin for it, such as a machine learning plugin.

ASIC Desgin:  RTL to GDSII

The RTL to GDS flow consits of the front-end and back-end designs, and we focus on the back-end design becuase it is time-consuming, especailly the detailed routing. After detailed routing, if congestion happens, we need to go back to the placement and global routing, to re-run the workflow. The repeated process can take a lot of time.
So we would like to use Machine learning models to enable early-stage prediction of routing congestion, so we don't have to run the detailed routing repeatedly.

Looking Ahead: From Open-Loop to Closed-Loop

Thant's it. In the fure, we would like to add a feedback loop, so that we can use the prediction results to improve the placement and global routing, to avoid congestion in the detailed routing.
